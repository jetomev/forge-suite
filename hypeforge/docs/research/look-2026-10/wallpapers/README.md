# The wallpaper generator moved

`generate.py` lived here while it was a research prototype. Since 10 October the look command (`applets/theme/hypeforge-theme`) draws every theme's wallpapers with it, so on 2026-10-17 it moved next to that command: **`applets/theme/wallpaper-generate.py`**. Its `--samples` set still lands in `samples/` here, with the research it belongs to.
