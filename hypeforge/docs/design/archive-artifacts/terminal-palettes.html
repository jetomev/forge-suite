hypeForge Terminal Palettes

Terminal colours, theme by theme

Finding F-12 from VM test 1: Alacritty's colours look bad in some themes. For each of the five hypeForge themes, the left terminal shows today's colours and the right one the proposal. The output is what you see in a normal day: the prompt, fastfetch, a file listing, git and error messages.

Why today's colours go wrong

A terminal has 16 colours. hypeForge builds them automatically from each theme, and on the light themes it gets "black" and "white" the wrong way round: "black" becomes a pale grey that almost disappears on the light background. The accent colours were also borrowed from the dark theme on the grey and black themes.

The proposal gives each theme a hand-picked set: Catppuccin Mocha's official terminal colours for the three dark themes, Catppuccin Latte's for the two light ones, with Latte's yellow, green and pink darkened so they stay readable on the light backgrounds.

How the system switch and alacrittyForge work together: hypeForge writes the chosen theme's terminal colours to ~/.config/alacritty/themes/hypeforge-current.toml, the same folder alacrittyForge's Themes section reads. Picking that entry in alacrittyForge means "follow the desktop"; picking any other theme there keeps that one for the terminal only.
