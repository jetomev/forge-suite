# Archived design pages (from claude.ai artifacts)

*2026-10-25. Javier's call: the KognogOS manual lives in the repositories' text files, shown in the built-in Help and on kognogos.org ("two places for the manual"); the old design artifacts on claude.ai are removed once they are kept here.*

These pages were approved designs and reviews, published as claude.ai artifacts. Their own repositories hold only the recipes that build them (the built pages were git-ignored), and some had no copy at all — so each page is kept here exactly as it was published (checked byte for byte against the artifact before the artifact was removed). The eight app screen designs that are already in git (displayForge, nogForge, grubForge, bitlaForge, alacrittyForge, workspaceForge, nightForge, defaultappsForge — each app's `docs/design/`) are not repeated here.

| Page | What it was |
|---|---|
| `look-build-plan.html` | hypeForge's look build plan (D-78), 2026-10-10 |
| `look-review-1.html` … `look-review-7.html` | the look reviews: the first sheet, then Windows 11, Mac OS 9, macOS, Rice, KDE, COSMIC (D-67…D-80) |
| `terminal-palettes.html` | the terminal palettes, 2026-09-30 |
| `wallpaper-themes.html` | KognogOS wallpaper themes, 2026-09-30 (its pictures in `wall/`; its one saved pick in `wallpaper-themes-db/`) |
| `sudoforge-design/` | sudoForge's design (a Design-type artifact: four drawings and its canvas; the password in the mock is made up) |

`wallpapers/` holds the pictures the look reviews show. Open any page in a browser straight from this folder.
