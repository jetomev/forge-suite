The Linux rice: floating islands, big gaps, see-through terminals, a mood on the wall

"Ricing" is what the Linux community calls dressing a desktop up by hand, the setups people show off on r/unixporn. This is our take: the bar breaks into three floating islands, workspaces are pills, terminals let the wallpaper glow through, and every theme brings its own generated wallpaper. It is the most terminal-proud of the six, so it fits the Forge Suite's philosophy best. Pick a theme and watch the whole mood change.

Honest limits

What this rice won't have

Not on Sway

  • Gradient window frames (one colour per state only).
  • Animated windows sliding and popping in: SwayFX's animations stay off (#565, #569).
  • Hyprland-only tricks people show off (wobbly windows, shaders on the screen).

Different on purpose

  • Every piece is a hypeForge piece: the islands are our bar, the pills our Workspaces, the launcher ours.
  • Nothing from swaync, eww or other big add-ons: our rules keep the install small.

For the theme apps later

The style file this page is drawn from

hypeforge/docs/design/look/styles/rice/style.toml

# hypeForge style · Linux rice — APPROVED by Javier 2026-10-10 (review 5, D-75)
#
# "Ricing" is what the Linux community calls dressing a desktop up by hand: floating bars,
# big gaps, rounded see-through terminals, a wallpaper that sets the mood. This style is our
# take, built from the same pieces as the others. Colours come from the active theme (D-73).

[meta]
name = "Linux rice"
slug = "rice"
schema = 1
needs = []                       # plain Sway: square windows, solid islands
better_with = ["swayfx"]         # rounded windows, see-through terminals and frosted islands
credit = "After the r/unixporn community's work, with thanks. Learned from, never copied."

[shape]                          # pixels, at 100 % scale
radius_window    = 12
radius_island    = 12            # the floating bar
radius_area      = 8             # its three areas inside it
radius_pill      = 999           # workspace pills
radius_popup     = 14
border_window    = 2             # a bright frame on the window in use
border_island    = 2
gap_inner        = 14
gap_outer        = 14
bar_height       = 38
bar_margin       = 10            # the islands float this far from the screen edge

[layout]
bar_position     = "top"
bar_style        = "one-island"  # one floating island with three areas (Javier, R-1)
bar_on           = "every-screen"
area_left        = ["emblem", "workspace-pills"]                 # pills: numbers; the active one wide, with its name (R-2)
area_center      = ["clock", "now-playing"]
area_right       = ["cpu", "memory", "network", "volume", "night-light", "tray", "power"]
launcher         = "fuzzel"      # restyled: centred, rounded, a bright frame
power            = "panel-buttons"  # big round buttons over a dimmed screen (R-5)
wallpaper        = "theme"       # the theme's own generated picture (D-75: every theme, every style)

[roles]
island_background  = "surface.base"           # frosted on SwayFX
island_border      = "band.base"
pill_active        = "band.base"
pill_active_text   = "band.on"
pill_busy          = "text.secondary"         # a workspace with windows on it
pill_empty         = "text.muted"
module_icon        = "pop.text"
window_focused     = "band.text"              # the bright frame (R-4)
window_unfocused   = "border.subtle"
terminal_background = "term.bg"               # 82 % on SwayFX, frosted
power_button_hover = "pop.base"

[fx]                             # SwayFX login only
corner_radius      = 12
shadows            = true
shadow_blur_radius = 24
shadow_offset      = [0, 6]
blur               = true        # islands, terminals, the launcher, the power menu
blur_passes        = 3
blur_radius        = 6
terminal_opacity   = 0.82        # Alacritty's own window.opacity, so the frosted wallpaper shows
default_dim_inactive = 0.08      # windows not in use dim a touch
animations         = false       # SwayFX #565/#569

[fonts]
ui      = "JetBrainsMono Nerd Font"  # rices lean on one mono font everywhere, icons included
ui_size = 10.5
mono    = "JetBrainsMono Nerd Font"
