# Midnight Commander (files)

**What it is:** the file manager in the terminal — two panels side by side, so copying and
moving between folders is one key. It wears the **KognogOS Mocha** look: blue folders, peach
marked files, mauve headers, rounded corners.

## How to use it

- Open it from the launcher (**Favourites → Midnight Commander**) or type `mc` in a terminal.
- **Tab** switches panel · **Enter** opens a folder or file · **Insert** marks a file (peach).
- The key bar at the bottom: **F3** view · **F4** edit (opens the file in **fresh**, KognogOS's editor) · **F5** copy · **F6** move or rename ·
  **F7** new folder · **F8** delete · **F9** the menu · **F10** quit.
- **Colours by kind:** folders blue, programs green, links sky blue, broken links red,
  archives pink, pictures sapphire, music and video flamingo, source code teal.

## Settings

The look: `~/.local/share/mc/skins/kognogos-mocha.ini` (a copy of `themes/mc/` in hypeForge),
chosen by `skin=kognogos-mocha` in `~/.config/mc/ini`. To try another look once:
`mc -S <skin>`. The Theme manager will switch looks for you later.

The editor: **fresh**, set for mc only (other programs keep theirs) — `use_internal_edit=false`
in `~/.config/mc/ini`, and mc started with `EDITOR=fresh` (the launcher entry, and the `mc`
fish function `themes/mc/mc.fish`). Back to mc's own editor: `use_internal_edit=true`.
