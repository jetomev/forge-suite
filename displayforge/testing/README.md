# displayForge — testing

Every version is tested on the KognogOS test desktop (three 1440p screens at 144 Hz) by Javier, plus the automatic tests, which drive the whole app in memory with a fake Sway and a fake brightness tool and check that no real file is touched. Each finding gets a number (F-1, F-2…) and an [issue](https://github.com/jetomev/forge-suite/issues).
