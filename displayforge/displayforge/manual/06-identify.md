# Identify

Screens that are the same model look identical to the computer, so it cannot tell which brightness control is which screen. Identify asks you **once** and remembers.

1. Press **Start**. One screen goes **dark for 3 seconds**, then comes back on its own.
2. Click which one it was: **left**, **middle**, **right**… (or **None of Them**, or **Dim It Again**). The buttons appear only after the screen is back.
3. Repeat for each screen. **Brightness** then has one row per screen.

**Names:** give your screens names — Main, Left, Gaming… — and press **Enter**. displayForge shows them everywhere.

Everything Identify learns is kept in `~/.config/displayforge/screens.toml`.
