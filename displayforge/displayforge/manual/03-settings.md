# Settings

Your screens on the left, the picked one's settings on the right. Everything offered is something the screen **really supports**: displayForge asks the screen, it never guesses.

| Setting | What it does |
|---|---|
| **On** | Switch a screen off (the others stay on). At least one must stay on. |
| **Resolution** | How many dots the picture has. The list holds only what this screen offers. |
| **Refresh rate** | How many times a second the picture is redrawn (Hz). Only the rates this resolution supports. |
| **Size of things** | 100 % is normal. Higher makes everything bigger. 80 and 90 % make things smaller — older apps (Steam, games through Wine) may then look slightly blurry. |
| **Rotation** | Turn the picture for a screen standing on its side. |
| **Smooth motion** | Adaptive sync (FreeSync): smoother games. Off by default; some screens flicker with it. |
| **HDR** | Only on screens that support it. |

Changes wait until you try them with **F9**.
