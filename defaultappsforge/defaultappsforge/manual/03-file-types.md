# File Types

Like workspaceForge's Apps page:

- **On the left**, the common file types on no default app yet, with **Find**. Tick them with **Space**.
- **On the right**, your default apps; open one to see its file types (opening another closes the first).
- **>>** assigns the ticked types on the left to the open default app; **<<** clears the ticked types of the open one (they go back to the system's own guess).
- **Select All (a)** / **Deselect All (u)** tick only the rows you can see.

A file type opens in the app you picked for its default app on Default Apps.

## Files

- `~/.config/mimeapps.list` — the choices (a backup before every save in `~/.config/defaultappsforge/backups/`, the last 20 kept).
- `~/.config/defaultappsforge/settings.toml` — which file types belong to which default app.
- `~/.config/xdg-terminals.list` — your terminal.
