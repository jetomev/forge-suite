# Getting started

defaultappsForge decides **which app opens what**: links, email, calendar invites, pictures, music, video, text, PDFs, folders, archives, maps, documents, and your terminal.

## The two pages

- **1 · Default Apps** — fourteen jobs under **Defaults**, each with a drop-down under **Selection** listing only the apps that can do it. Pick one; nothing changes until you save.
- **2 · File Types** — the common file types and which default app opens each (see that page).

## Saving

**F10** shows a review of every change, makes a backup of the old file, and applies at once: the next file or link you open uses it. Old choices for apps that are no longer installed are tidied away, and the review says so.

It writes the standard file every Linux desktop and app reads, `~/.config/mimeapps.list`, so it works with any desktop, or none, and from a plain text console too.

**1 – 3** or **Ctrl** + the underlined letter move between pages; **?** shows every key; **Q** quits (it asks if something isn't saved).
