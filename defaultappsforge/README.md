# defaultappsForge

**Which app opens what.** Links, folders, text, PDFs, pictures, music, video, documents and archives: see what opens each today (your choice, or just the system's guess), spot old choices for apps that are gone, and pick. A terminal app, and the Default apps page of hypeForge Settings.

> 🖥 **Where it runs:** **any Linux distribution** · **any desktop, or none**: it writes the standard `~/.config/mimeapps.list` that Sway, KDE, GNOME and every app read · **any terminal, even a plain text console**.
