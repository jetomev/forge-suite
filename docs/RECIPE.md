# The recipe — one app per job

*For every job a bare Hyprland desktop needs, this page lists **up to five of the most reviewed and recommended options**, each with links showing how it works. **Javier chooses** ([D-11](DECISIONS.md#d-11--the-recipe-up-to-five-researched-options-per-job-and-javier-chooses)). A line marked "Claude's lean" is a suggestion, not a decision.*

> **Status: research in progress (started 2026-09-28).** The option tables arrive here, with their sources, as each job is researched.

---

## The first choice: one program, or many small ones

In August 2026, Omarchy 4, our reference, replaced its separate small apps with **one all-in-one desktop program** built on [Quickshell](https://quickshell.org). One process now runs the bar, launcher, notifications, on-screen pop-ups, control panels, lock screen and password pop-up. Before that, Omarchy used separate apps: Waybar, Walker, Mako, SwayOSD, hyprlock, hypridle, swaybg and polkit-gnome.

| | One all-in-one program | Separate small apps |
|---|---|---|
| **How it feels** | One consistent design, and the pieces know about each other | Each piece is swappable on its own |
| **Weight** | One larger program, always running | Several small programs |
| **Fits "light, terminal-first"?** | Less naturally | More naturally |
| **Settings** | One place, in that program's own format | One file per app, easy to keep in the portable folder |

This choice comes first because every other row depends on it.
